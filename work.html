Frodecorp

A digital website creation concept built around a canvas based editor. The project explores how far visual composition can go before code becomes the easier route. It is a concept, not a finished product, and it shows what a more visual approach to building a site could look like.

Project 05 Experimental

CSIC

Comepty Super Intelligence Connection is an experimental Windows based assistant exploring the connection between artificial intelligence and desktop productivity. It works with AI assisted computer interactions, file operations and development workflows.

CSIC is an experiment, not a finished commercial product. Its behaviour and scope keep changing as the underlying models develop, and it is presented here in that state on purpose.
